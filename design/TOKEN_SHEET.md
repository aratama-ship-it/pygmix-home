# 音のメモ：アイコン設計メモ

## 目的

MacのJISキーボードを押すだけで、音階や短いメロディを即座に確認できることを、アプリアイコンと配布ページの小さな表示でも伝える。

## 設計判断

- **使う場面**: Dock、配布ページの見出し、ファビコン。16pxでも「入力中」のアンバーが残る必要がある。
- **感じてほしいこと**: 楽器アプリの装飾性ではなく、すぐに押して試せる小さな作業道具。
- **固有の核**: PCキーを押して音階を試すアプリだが、表示される音の並びは実際のピアノ鍵盤に沿う点。
- **採用**: 7本の白鍵に、黒鍵を `2 + 3` で並べる1オクターブの鍵盤。アンバーは右から2番目の白鍵（A）の押下状態だけに使う。
- **不採用**: 黒鍵が均等に並ぶ抽象グリッド、音符、波形、グラデーション。鍵盤の規則を崩し、即時に音程を読む用途に合わないため。

## トークン

| 種別 | 値 | 用途 |
| --- | --- | --- |
| Paper | `#F9F6EE` | 本体と通常キー |
| Ink | `#1F1F1C` | 外枠・入力面 |
| Accent | `#E88F1F` | 押下中の白鍵 |
| Canvas | `#FFFFFF` | PNG書き出し時の背景 |
| Safe area | 72 / 1024 | OSマスクで欠けない外周余白 |
| Corner | 196 / 1024 | Macらしい大きい角丸 |
| White keys | 7 | C—B の1オクターブ |
| Black keys | 5 | C♯・D♯ / F♯・G♯・A♯ の `2 + 3` |

## 案

1. **Piano Octave（採用）** — 白鍵7本と黒鍵5本を、実際の `2 + 3` の位置関係で配置。音程を確かめる用途が最短で読める。
2. **PC Key Grid（不採用）** — JIS入力の由来は出るが、黒鍵の規則が読めない。
3. **Take Strip（不採用）** — 録音機能は出るが、音階確認の主用途から遠い。

## 確認基準

- 16 / 32 / 64 / 128px で、白鍵の列と黒鍵の `2 + 3` が判別できる。
- モノクロ表示でも、枠・入力面・キーの3層が判別できる。
- 逆さでも文字情報に依存せず、キー入力の抽象形として破綻しない。
- 既存ページの紙色・墨色・アンバーだけで完結する。
