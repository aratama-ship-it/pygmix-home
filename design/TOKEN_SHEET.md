## 0. 設計メモ（design-policy.md の5つの問い）

1. **誰が・どの場面で**: pygmix.com のトップに来た人が、最初の数秒で「いま何を見てほしいか」を受け取る場面。
2. **どんな気分に**: 「流れ続けている作品の中から、今日はこの一枚を引き上げて見せている」という、選ばれた感じ。押したくなること。
3. **固有の核**: このヒーローは**回転寿司の比喩**でできている。作品は「皿（色の付いた楕円の縁）」に載り、「コンベアのレール」を52秒で1周し、左右に「入口 IN / 出口 OUT」の門がある。この語彙が pygmix 固有の核。
4. **踏襲するもの / 意図的に外すもの**
   - 踏襲: 皿の縁（5px・4色循環）、カードの角丸 `52px 8px 52px 8px`（対角だけ極端）、1px の細罫、紙色の地、極小モノスペース（6〜7px・字間0.16em）、門の「上は角・下は丸」の札。
   - 外す: 四隅が同じ半径の角丸カード、ピル型バッジ、大きめの影。**前の版はこれらで作っていた＝どのサイトにもある一般的なカードだった。**
5. **守る機能条件**: 流れる皿・門・中央の円と重ならない（19通りの画面で実測）／タップ44px以上／コントラスト4.5:1以上／`prefers-reduced-motion` で動きを止める／画像は同梱済みの640×336を使い、追加の読み込みを増やさない。

## 4. 大きさと置き場所（実測で決めた数値）

画像は 640×336（比 1.905）。**カードの高さ＝幅÷1.905**なので、幅を決めると高さが決まる。
置ける高さは「円の上端 − 上の余白 − 円との間隔 − 皿のはみ出し」で決まり、円の位置は画面の高さで動く。

```
--pickup-room: calc(50vh - 50px - clamp(310px, 29vw, 390px)/2 - 38px)
width: min(420px, 70vw, calc(var(--pickup-room) * 1.905))
```

| 画面幅 | カード幅 | 根拠（1周52秒・全皿で実測） |
|---|---|---|
| 〜1100px | 上の式（1440×900で約318px、1440×1080で420px） | 円のすぐ上は皿が来ない |
| 1100px以下 | 350px | 上部へ逃がす。皿が円の上を通るため |
| 1000px以下 | 276px | 292pxだと900pxで円の上端180pxに接する |
| 560px以下 | `min(168px, 38vw)`・上端22px | ★皿の縁を含めた当たりで測る。42vwだと390pxで皿込み下端112px＝コンベアの皿（y=110まで）に当たり、320pxでは皿の左端81pxが隅ラベル（x18〜89）に当たる |
| 560px以下の皿の張り出し | 左右+8px／上下+5px／縁3px | カードが168pxまで縮むため、既存の+20/+7・5pxのままだと皿が支配的になる |

### 実測（皿の縁を含めた当たり判定・1周52秒）

1440×900 / 1440×1080 / 1920×1080 / 1366×768 / 1280 / 1100 / 1050 / 1000 / 950 / 900 / 860 /
820 / 768 / 600 / 560 / 500 / 430 / 414 / 390 / 375 / 360 / 320px の**22通り**で、
流れる皿・隅のラベル・中央の円のいずれとも重ならず、画面内に収まることを確認した。
1440×900でカード318×168（皿込み356×180）、1440×1080でカード420×221（皿込み458×233）。
